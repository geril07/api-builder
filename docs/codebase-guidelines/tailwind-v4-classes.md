# Tailwind CSS v4 class renames

Some utility classes were renamed in Tailwind CSS v4. Use the v4 names in all new code, and migrate when touching old code.

## Overflow-wrap

| v3 (deprecated) | v4 (current)      |
| --------------- | ----------------- |
| `break-words`   | `wrap-break-word` |
| `break-all`     | `wrap-anywhere`   |
| `break-normal`  | `wrap-normal`     |

## Whitespace

| v3 (deprecated)     | v4 (current)  |
| ------------------- | ------------- |
| `whitespace-nowrap` | `text-nowrap` |
