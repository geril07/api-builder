# Codebase Guidelines

Load this skill before writing any code. It tells you to consult `docs/codebase-guidelines/index.md` for the list of guidelines.

## Workflow

1. Read `docs/codebase-guidelines/index.md` to find entries relevant to what you're touching.
2. Read the matching file(s) in `docs/codebase-guidelines/`.
3. Follow the pattern described.

## Adding a new guideline

1. Create `docs/codebase-guidelines/<name>.md` with the pattern.
2. Add a row to `docs/codebase-guidelines/index.md`.

If you encounter something non-obvious or unexpected while writing code, ask the user if it should be added.
